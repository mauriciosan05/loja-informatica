# Loja de Informática

Site de cadastro e listagem de produtos de uma loja de informática, organizados por seção (Computadores, Acessórios, Impressoras, Games, Gadgets) e marca (HP, Dell, Positivo, Asus, Xing Ling genérico). Projeto acadêmico feito em dupla para a disciplina de Programação WEB 2 (PRW2).

## Funcionalidades

- Cadastro de produtos com validação (campos obrigatórios e preço maior que zero)
- Produtos organizados automaticamente por seção
- Identidade visual por marca (logo ou cor de destaque)
- Navegação fixa no topo com atalho para cada seção

## Tecnologias

- React
- Vite
- CSS puro (sem framework de UI)

## Como rodar localmente

```bash
npm install
npm run dev
```
